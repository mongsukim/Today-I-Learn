# 2026 커밋 기반 작업 정리

- 대상: **A 앱 FO** (통근 예약·결제 하이브리드 앱), **B 앱 FO** (오피스 생활 서비스 앱)
- 기간: 2026-01-01 ~ 2026-10-22
- 기준: 본인 커밋만 집계함. 머지 커밋과 브랜치 간 중복 커밋은 제외함. 여러 분기에 걸친 작업은 주된 작업 시기에 배치함

### A 앱 FO 흐름

- **1~2월 — 회원가입 개편**
  - 임직원/파트너 가입 유형, 사원번호 인증 바텀시트 구현
  - 피처플래그 기반 배포
  - 내정보·비밀번호 변경, 로그아웃 시 캐시 정리, 코치마크 구현
- **3월 — 안정화와 안드로이드 대응**
  - QR 탑승권, 초대코드 재인증, 장기미사용 잠금 해제 구현
  - 안드로이드 키보드 가림 현상 수정
  - 에러 모니터링 이슈 집중 처리 (lazy chunk 로드 실패, 이미지 뷰어, 푸시 토글, unhandled rejection)
- **4월 — 리팩터링과 예약·결제 착수**
  - 아이디/비밀번호 찾기 구현
  - API 에러 처리 통일, 긴 컴포넌트 분리
  - AI 코딩 규칙 문서·QA 자동화 스킬 도입
  - 결제 작업 착수 (PG SDK, 날짜 선택, 예약 확인, 이용내역 mock)
- **5~6월 — 예약·결제·본인인증 실제 연동**
  - 다회차 노선, 날짜별 요금, 회차 선택 연동
  - 결제를 리다이렉트 방식으로 변경, 중복 결제 방지
  - QR·홈 탑승권 실제 API 연동
  - 본인인증 SDK 직접 호출로 변경, 사내 본인인증 모듈 연동
  - 안드로이드 외부 앱 복귀 처리
- **7월 — v2 UI 전면 리뉴얼** (3Q 상세 참고)
- **8~9월 — QA 마무리**: 피그마 불일치 일괄 수정, 9월 초 마지막 커밋

### B 앱 FO 흐름

- **5~6월 — v2 디자인 시스템 시작**
  - 디자인 시스템 컴포넌트·토큰 구축
  - 홈 v2(스켈레톤, 개인화 문구, 위젯), 불편신고 v2, 근무위치 설정 구현
  - 건물 커뮤니티 게시글 상세 구현 (76건)
  - 인증 QA 일괄 처리
- **7~9월**: 3Q 상세 참고
- **10월**: 4Q 상세 참고

### 공통적으로 보이는 점

- **반복해서 다룬 영역**: 하이브리드 앱의 키보드, safe-area, 뒤로가기, 외부 앱 복귀, 피그마 일치, alert → 인라인 에러 전환
- **일하는 방식**
  - 피처플래그로 단계적 오픈 → v1/v2 병행 → 전환 후 v1 정리
  - AI 코딩 규칙·QA 자동화를 A 앱에서 먼저 적용 후 B 앱으로 확장
- **최근 변화**: 9월 이후 화면 기능보다 GA 계측 레이어, 코드 정리, 성능 개선 등 구조 작업 비중이 커짐
